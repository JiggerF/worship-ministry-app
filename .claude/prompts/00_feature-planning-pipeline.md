We are planning a new product feature.

Your job is to simulate a full engineering planning cycle similar to what a mature software team would perform before implementation.

Execute the following phases sequentially.

-----------------------------------

PHASE 1 — Feature Definition

Define:

1. Problem Statement
2. Target Users
3. Expected Outcome
4. Constraints
5. Risks
6. MVP Scope
7. Future Extensions

-----------------------------------

PHASE 2 — Architecture Design

Design the system architecture.

Include:

1. System Overview
2. Data Model Changes
3. Service Layer Design
4. API Design
5. Tenant Isolation Considerations
6. Failure Modes
7. Migration Strategy
8. Simpler Alternatives

-----------------------------------

PHASE 3 — Implementation Plan

Produce a step-by-step engineering plan.

Break down:

1. Preparation tasks
2. Database changes
3. Backend service updates
4. Frontend changes
5. Agent logic changes
6. Data migration steps

Focus on minimizing production risk.

-----------------------------------

PHASE 4 — Test Strategy

Design a test plan.

Include:

1. Unit tests
2. Integration tests
3. End-to-end tests
4. Edge cases
5. Failure scenarios
6. Multi-tenant isolation tests
7. AI agent behavior tests

-----------------------------------

PHASE 5 — Release Strategy

Provide a safe rollout plan.

Include:

1. Risk assessment
2. Feature flag strategy
3. Migration plan
4. Monitoring plan
5. Rollback plan

-----------------------------------

PHASE 6 — Critical Design Review

Now challenge the entire design.

Identify:

- hidden complexity
- scalability risks
- architectural mistakes
- simpler solutions

Recommend improvements if needed.

-----------------------------------

Produce a structured planning document.
Focus on simplicity, safety, and maintainability.
